# guildHordeWOWClassic Wiki

Bem-vindo à wiki do projeto `guildHordeWOWClassic`.

Esta wiki resume os principais pontos da API REST para gestão de guildas da Horda em World of Warcraft Classic, com foco em visão geral, regras de negócio, endpoints, modelo de dados, testes e execução local.

## Resumo do projeto

- API REST em `Node.js`, `Express` e `MySQL`
- autenticação com `JWT`
- documentação em `Swagger/OpenAPI`
- testes unitários, de integração/API, concorrência e performance
- pipelines com `GitHub Actions` para CI e performance

## Funcionalidades principais

- cadastro de usuário
- login
- criação de guilda
- listagem de guildas
- cadastro de integrante na própria guilda
- alteração da própria função
- alteração de cargo de integrante
- remoção de integrante da guilda
- saída da guilda
- deleção da guilda
- listagem de usuários com filtros, paginação e ordenação
- listagem de integrantes de uma guilda
- deleção do próprio usuário
